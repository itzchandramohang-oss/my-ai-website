# AI Chat Website

A beginner-friendly website with an AI chat feature.

## About

The frontend uses HTML, CSS, and JavaScript. The backend uses Node.js and Express to send messages to the OpenAI API and return AI-generated replies.

## Setup

1. Install Node.js.
2. Add your OpenAI API key to a local `.env` file.
3. Install the backend packages.
4. Start the backend server and open the website.

## Security

Never upload your `.env` file or share your API key.
